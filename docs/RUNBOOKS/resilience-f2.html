Escenario 3 — Alerta de deriva ledger

Objetivo: confirmar que cuando la VRAM real difiere del ledger más de 512 MB, la API emite un WARN en logs.

1
Buscar warnings de deriva en logs de la API
Claude
VPS
docker compose -f ~/ai-worker-platform/deploy/vps/docker-compose.yml logs api | grep -i "vram drift"
api-1 | 2026/06/13 04:37:03 WARN vram drift: gpu_id=ialab/gpu-0 ledger_free_mb=16376 reported_free_mb=15450 delta_mb=926 margin_mb=512
api-1 | 2026/06/13 04:47:29 WARN vram drift: gpu_id=ialab/gpu-0 ledger_free_mb=16376 reported_free_mb=14651 delta_mb=1725 margin_mb=512
api-1 | 2026/06/13 04:47:40 WARN vram drift: gpu_id=ialab/gpu-0 ledger_free_mb=16376 reported_free_mb=14681 delta_mb=1695 margin_mb=512
El ledger dice 16376 MB libres (sin jobs en vuelo, vram_reserved_mb=0), pero la GPU real tiene ~1.7 GB ocupados por el SO y los drivers. La deriva supera el margen de 512 MB → WARN correcto. No hay corrección automática del ledger (comportamiento esperado en F2; la corrección es F3+).
